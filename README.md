# 관악기 연습 도우미 — 클라리넷·플룻 (v0.10)

입문자를 위한 클라리넷(뷔페 B12)·플룻(야마하 YFL-222) 연습 앱입니다. 설정에서 악기를 바꾸면 운지·음역·이조·샘플·연습곡이 그 악기로 바뀌고, 기록·악보·설정은 악기마다 따로(IndexedDB `clarinet-practice` / `flute-practice`) 저장됩니다. 악기마다 다른 것은 `src/instruments/profiles.ts`, 연습곡은 `src/exercise/curriculum.ts` 의 `curriculumFor`. 바이올린 연습 도우미(v0.8)를 바탕으로 만들었고, 튜너·메트로놈·악보 채점·녹음·연습 기록은 그대로 쓰고 클라리넷에 맞게 바꿨습니다.

## 악보음과 실음
앱의 음 이름, 운지, 채점은 모두 **악보음**(클라리넷 파트 악보에 적힌 음)으로 합니다. 마이크로 들은 소리는 악기 설정(B♭·A·E♭·실음)에 맞춰 악보음으로 바꾸고, 앱이 내는 소리(기준음·드론·악보 듣기)는 반대로 실음으로 바꿔서 냅니다. B♭ 클라리넷에서 악보 C5 = 실음 B♭4.

## 기능
- **오늘**: 루틴(조립·리드·튜닝 → 롱톤 → 텅잉 → 음계·연습곡 → 곡 연습 → 복습) 타이머, 오늘의 기초 연습 추천(다음 단계 연습곡 + 텅잉 변형)
- **튜너**: 악보음 이름 + 음역(샬뤼모·스로트·클라리온·알티시모) + 실음 이름, 지금 부는 음의 운지 그림. **조율하기**: C5(실음 B♭)·열린 G·B4·D4 를 1.5초 평균으로 재고 "배럴을 빼세요/넣으세요" 안내
- **운지**: E3~G6 운지표(기본·다른 운지, 팁), 오선 표시, 소리 듣기. 마이크를 켜면 부는 음의 운지로 바뀜. **운지 퀴즈**: 오선의 음을 보고 불면 0.4초 뒤 정답 처리
- **기초** (롱톤 · 텅잉 · 넘기 · 따라 불기 · 음정·드론)
  - 롱톤: 음·목표 시간(4~20초)·모양(일정하게 / 작게→크게→작게). 끝나면 길이, 평균 음정, 음정 흔들림(±센트), 소리 크기 흔들림, 끝에서 처지는지, 크게 불 때 음정 변화(센트/dB), 그래프와 조언. 기록 저장(오늘·전체 최고 길이)
  - 텅잉: 템포·리듬(4분~16분)·마디 수, 한 마디 세고 시작. 어택(혀로 끊은 뒤 다시 커지는 순간)을 5ms 단위로 찾아 박과 비교 → 맞춘 음, 평균 어긋남(ms), 간격 흔들림(%), 빨라짐·느려짐. 통과하면 ♩+4 추천
  - 음정·드론: 드론(악보음 기준, 실음으로 재생) + 순정률/평균율 음정, 음별 평균 오차
- **메트로놈**·**템포 트레이너**: 바이올린 앱과 같음
- **악보**: MusicXML 불러오기(여러 파일 한꺼번에, 같은 악보는 건너뜀)·채점·듣기(실제 클라리넷 샘플, 실음으로)·반주·연습 기록. 내 파트에 이조 표시(`<transpose>`)가 있으면 그 값으로, 없으면 악기 설정으로 소리를 냄
- **악보 듣기 표현** (v0.4, "셈여림·아티큘레이션 살리기" 체크로 끄고 켬): 스타카토는 짧게, 슬러 안 음은 혀 없이 이어서(샘플 어택을 건너뜀), 테누토는 끝까지, 악센트·sf 는 세게. p·mf·f 등 셈여림과 크레셴도·디미누엔도 쐐기, 페르마타 늘이기, rit./rall. 은 점점 느리게, a tempo 로 복귀. 채점에는 영향 없음 (반주·클릭도 같은 시간에 맞춤)
- **연습곡 · 쉬운 곡** (악보 탭 → 연습곡 만들기)
  1. 첫 소리: 왼손 세 음 → 다섯 음 → 스로트 음 → 오른손 → 새끼손가락 키
  2. 쉬운 곡: 뜨거운 십자가 빵, 떴다 떴다 비행기, 반짝반짝 작은 별, 나비야, 환희의 송가, 징글벨, 달빛 아래서 (모두 저작권 끝난 선율)
  3. 낮은 음역 음계: F·G장조, 분산화음, 반음계
  4. 브레이크 넘기: 12도 올리기(레지스터 키), 스로트↔클라리온 2음, 환희의 송가·작은 별 G장조, C·F장조 음계 (넘는 음은 채점 뒤 따로)
  5. 클라리온 음계·에튀드: 2옥타브 음계·분산화음, 3도, 에튀드(매번 새로 만들기)
  - 텅잉·슬러 연습: 기본 악구 4개 × 16가지 아티큘레이션
- **기초 탭 넘기** (v0.5): 브레이크(A4↔B4, B♭4↔C5, G4↔D5, A4↔C5, 12도)·플룻 C♯5↔D5·옥타브를 번갈아 불면 넘어갈 때 끊긴 시간(ms)과 끽 소리를 재서 점수·조언
- **기초 탭 따라 불기** (v0.5): 앱이 2~6음 악구를 악기 소리로 들려주면 따라 불고 채점. 3번 연속 다 맞히면 한 음 늘고, 두 번 연속 절반 못 맞히면 줄어요. 음 묶음(왼손 세 음 → 클라리온)
- **템포 사다리** (v0.5, 악보 채점): 목표 템포로 한 마디 세어 주고 채점, 맞은 음 90% 이상 + 템포 지키면 ♩+4. 악보마다 최고 템포, 연결한 곡의 지금 템포도 올림
- **틀린 마디 복습함** (v0.5): 채점에서 틀린 마디(다른 음·놓침·평균 ±20센트 넘음)를 모아 오늘의 연습에 보여주고, 복습 날 깨끗하게 치면 1→2→4→7→14→30일 간격으로 늘어나다 졸업
- **도돌이표대로 듣기** (v0.5): 도돌이표·1·2번 괄호·times 를 펼쳐 재생 (채점은 악보 순서 그대로)
- **리드 기록** (v0.5, 플룻은 헤드조인트 위치): 지금 쓰는 리드를 고르면 롱톤·텅잉·넘기·채점 기록에 함께 남고, 리드별로 롱톤 흔들림·가장 길게·맞은 음 비교
- **기록**: 달력, 연속 일수, 곡(교재·레슨·합주·좋아하는 곡), 녹음과 비교
- **기록 → 분석** (v0.5): 주별 추이(연습 시간·롱톤·텅잉 통과 템포·악보 맞은 음·넘기·따라 불기, 표로 보기), 음정 습관 지도(최근 14/30/90일 음별 평균 높게·낮게 + 고치는 법, 전체가 높거나 낮으면 배럴·헤드조인트), 리드 기록

### v0.10

```
npm.cmd run dev        # PC에서 http://localhost:5173
npm.cmd run phone      # 같은 와이파이의 휴대폰에서 https://<PC IP>:5173
npm.cmd test           # 단위 테스트
npm.cmd run smoke      # 빌드 + 가짜 마이크로 전체 흐름 (Playwright)
```

## 휴대폰에서 쓰기 (GitHub Pages 배포)
`main` 브랜치에 올리면 `.github/workflows/deploy.yml`이 테스트 → 빌드 → 배포를 자동으로 합니다.
앱 주소: `https://<GitHub 아이디>.github.io/clarinet-practice/`

처음 한 번만:
1. GitHub에서 `clarinet-practice` 저장소를 새로 만들기 (Public, README 없이)
2. 명령 프롬프트에서
```
cd "%USERPROFILE%\OneDrive - 에이비스\문서\개인\개발 프로젝트\clarinet\clarinet-practice"
git remote add origin https://github.com/<GitHub 아이디>/clarinet-practice.git
git push -u origin main
```
3. 저장소 Settings → Pages → Source 를 "GitHub Actions" 로
